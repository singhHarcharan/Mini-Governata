var allowed = map[Status]map[Action]Status{
    Pending:    {Start: InProgress, Cancel: Cancelled},
    InProgress: {Complete: Completed, Cancel: Cancelled},
}

func (t *Task) Apply(action Action, actor string, now time.Time) error {
    next, ok := allowed[t.Status][action]
    if !ok { return fmt.Errorf("%w: %s from %s", ErrInvalidTransition, action, t.Status) }
    if action == Complete && actor != t.Assignee { return ErrNotAssignee }
    t.Status, t.UpdatedAt = next, now
    return nil
}

A transition is current state + action + context → next state or error. Centralize it so HTTP, workers, and messages cannot invent their own rules.

Audit

Current state answers “what”; audit answers “how”

type AuditEntry struct {
    ID         string
    TenantID   string
    ActorID    string
    Action     string
    EntityType string
    EntityID   string
    Before     map[string]any
    After      map[string]any
    OccurredAt time.Time
    RequestID  string
}

Audit entries should be append-only, ordered, attributable, tenant-scoped, and created in the same database transaction as the state change. Redact secrets and minimize sensitive values; “audit everything” can become a privacy leak.

return repo.WithTransaction(ctx, func(tx Tx) error {
    task, err := tx.Tasks().FindForUpdate(ctx, tenantID, taskID)
    if err != nil { return err }
    before := task.Snapshot()
    if err := task.Apply(Complete, actorID, clock.Now()); err != nil { return err }
    if err := tx.Tasks().Save(ctx, task); err != nil { return err }
    return tx.Audit().Append(ctx, NewAudit(actorID, before, task.Snapshot()))
})

Time

Inject a clock so deadlines are testable

type Clock interface { Now() time.Time }

func IsOverdue(task Task, now time.Time) bool {
    return task.Status != Completed && task.DueAt != nil && now.After(*task.DueAt)
}

Passing or injecting time makes boundary tests deterministic. Store instants in UTC; format in the user’s zone at presentation time. Decide whether a deadline is inclusive and encode that decision in tests.

Deep dive: duration versus calendar time

24*time.Hour means elapsed duration. “Next business day at 9:00” is a calendar rule involving location, weekends, and holidays. Do not confuse them.

SLA monitor

A worker is a loop with a lifecycle

func (m *Monitor) Run(ctx context.Context) error {
    ticker := time.NewTicker(m.interval)
    defer ticker.Stop()
    for {
        select {
        case <-ctx.Done(): return ctx.Err()
        case now := <-ticker.C:
            if err := m.checkOverdue(ctx, now); err != nil { m.log.Error("sla check", "err", err) }
        }
    }
}

select waits for whichever channel is ready. Cancellation is a normal shutdown signal. One item failing should not silently kill the monitor; decide retry/reporting behavior explicitly. Multiple replicas require idempotency or work claiming so alerts are not duplicated.

The UI map guides the user; it does not secure the transition. If another user changes the task, the server may return 409. Refetch and explain the new state. Render the audit timeline from server entries rather than constructing history locally.

Knowledge check

1. Why save audit and state in one transaction?

Show answer
Otherwise a crash can create state without evidence or evidence without state. Atomicity preserves their relationship.

2. Why inject time?

Show answer
Tests can control boundary instants exactly, and domain rules are not coupled to the wall clock.

3. What should a worker do on cancellation?

Show answer
Stop accepting/starting work, finish or abandon according to the defined deadline, clean resources, and return normally.
